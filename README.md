# Сайт-портфолио Нуриддина Ахмедова

Адрес: https://nuriddinbro.github.io

## Как обновить текст

1. Откройте нужный файл на GitHub и нажмите на значок карандаша (Edit).
   - `index.html` - русский текст.
   - `script.js` - английский текст (ищите по ключу из `data-i18n`).
2. Исправьте текст и нажмите зеленую кнопку **Commit changes**.
3. Через 1-2 минуты изменения появятся на сайте.

## Резюме

Загрузите файл с именем `resume.pdf` (Add file -> Upload files). Кнопка "Скачать резюме" заработает сама.
